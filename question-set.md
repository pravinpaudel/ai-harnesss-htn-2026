# Question Set — RBC sample questions

Supplied by RBC. Judging-day questions will be similar. Every question asks **which company** matches several clues, so answering means combining evidence from one company's quarterly narrative (the `<details>` blocks in §6 of each report), not looking up a single number.

The answer key was checked against the three reports. Each entry gives the company, the quarter the clues describe, and the lines in the source file that support it. **Medium** confidence means the company is clear but one clue is loosely worded or matches a different quarter; the note says which.

Source files: `canadian-financials-research.md`, `canadian-mining-research.md`, `canadian-technology-research.md`.

## What these questions need from the harness

- **Identification, not lookup.** The answer is a company. The evidence is several clues spread across one company's narrative for one quarter. The harness must search for each clue, find the company and quarter that satisfy all of them, and cite a source for each clue.
- **Narrative evidence is essential.** Most clues ("stock fell 5.83% on the release date", "first anodes", "GAAP loss optics") exist only in the quarterly `<details>` prose, not in tables. Chunks from those blocks have to be extracted and searchable.
- **Approximate wording.** Questions paraphrase: "crushed consensus by 13%" versus "Beat (+13%)", "tens of billions" versus "$56–62B", "just over 1%" versus "1.3%". Keyword search alone will miss some of these.
- **Near-misses exist.** Several questions have a second company that matches some of the clues (BNS for #2 and #7 in financials). The answer should explain why the chosen company matches all the clues.
